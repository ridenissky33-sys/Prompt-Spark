# ✨ Prompt Spark

A tiny, dependency-free web app that generates random cinematic prompts for AI video and image tools.

## Run

Open `index.html` in a browser. No build step.

## Deploy

Enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Idea

Subject + place + style + mood, randomly combined. Extend the word lists in `index.html` to taste.
